# ReKeyLab

**Offline password-recovery and protection-removal tools for Siemens industrial automation.**

ReKeyLab builds open, offline utilities that help the **rightful owner** of a PLC / HMI project regain access when a password is lost — across **Siemens S7 (STEP 7 / TIA Portal)** and **WinCC / WinCC flexible HMI** projects. Everything runs locally on your own project files. No cloud, no data collection, no equipment required.

> ⚙️ **Focus:** STEP 7 / S7-300 / S7-400 / S7-1200 / S7-1500 · TIA Portal · WinCC HMI · lost-password recovery · ICS/OT security research.

---

## 🔧 Tools

| Project | What it does |
|---|---|
| **[S7BlockUnlocker](https://github.com/ReKeyLab/S7BlockUnlocker)** | Removes know-how block protection from STEP 7 program blocks (Classic, S7-300/400) in offline project files. |
| **[S7CredExtractor](https://github.com/ReKeyLab/S7CredExtractor)** | Recovers the S7-300/400 CPU protection password offline from an MMC memory-card image. |
| **[FwxAnalyzer](https://github.com/ReKeyLab/FwxAnalyzer)** | Analyzer / unpacker for WinCC flexible (`.fwx`) and TIA Portal (`.fwc`) operator-panel project images. |
| **[ReKeyLab.github.io](https://github.com/ReKeyLab/ReKeyLab.github.io)** | Landing page for the Siemens S7 & HMI tool collection. |

---

## 🔎 What ReKeyLab helps with

- Lost or forgotten **TIA Portal / STEP 7 project passwords**
- **Know-how–protected** program blocks you own but can no longer edit
- **S7-300 / S7-400 CPU protection** passwords from an MMC image
- Reading and analyzing **WinCC flexible / TIA HMI** project files
- Education and **ICS/OT security research** in industrial automation

---

## ⚖️ Intended use

These are **research and recovery** tools intended for:

- the **legitimate owner** of the project, PLC, or equipment recovering their own lost access;
- **education** and defensive **security research** in industrial control systems.

Do **not** use them against systems, projects, or equipment you do not own or are not explicitly authorized to work on. You are responsible for complying with all applicable laws and agreements.
